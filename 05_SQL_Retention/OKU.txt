SQL kohort ve retention

Bu PBIP proje taslağı, Windows Power BI Desktop'ta henüz açılıp doğrulanmadı.
Kullanıcının talebiyle Desktop'a aktarım/açılış sonraki aşamaya bırakıldı.

Sonraki aşama:
1. 05_SQL_Retention.pbip dosyasını güncel Windows Power BI Desktop ile aç.
2. Home > Refresh ile gömülü snapshot'ı yükle. CSV yolu/API anahtarı gerekmez.
3. CHECKS.json değerleri, kartlar, tablo toplamları ve etkileşimleri kontrol et.
4. Başarıyla doğrulandıktan sonra .pbix kaydet; yayın, GitHub ve CV ayrı aşamadır.
